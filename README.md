# 校园问卷互助积分平台 (Web MVP)

本项目为南阳师范学院第二十三届“张衡杯”大学生课外学术科技作品竞赛 - 科技发明制作B类（信息技术）参赛作品。

## 项目简介
本项目针对在校大学生调研问卷收集困难、填写率低、付费刷问卷导致数据虚假的痛点，设计了一款基于“积分互助”机制的轻量级 Web 原型。
用户通过填写他人问卷获取积分，消耗积分发布个人问卷，实现校内学生的互帮互助与真实数据收集。

## 技术栈
- 前端基础：HTML5 + CSS3 + 原生 JavaScript
- UI 框架：Bootstrap 5 (CDN 引入)
- 数据存储：浏览器本地存储 localStorage (用于模拟后端数据流转)
- 协作工具：Git + GitHub

## 本地运行指南
1. 克隆本仓库到本地：`git clone <仓库链接>`
2. 使用 VS Code 打开项目文件夹。
3. 安装并启用 Live Server 插件。
4. 在 index.html 文件上右键，选择 Open with Live Server 即可在浏览器中体验完整流程。

## 核心业务流程
1. 赚积分：在首页点击问卷 -> 进入详情页 -> 点击“提交问卷” -> 积分增加，按钮置灰（防重复机制）。
2. 花积分：点击底部“发布问卷” -> 填写表单 -> 点击发布 -> 扣除积分并返回首页。
3. 数据查看：在“我的”页面查看当前积分及互助记录。

当前版本为静态 Web 高保真原型。后续计划采用 Vue3 + UniApp 迁移至微信小程序，并接入后端数据库，完善用户管理、动态表单生成与更严格的防敷衍校验。
