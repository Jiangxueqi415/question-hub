# 互答有据 - 校园问卷互助系统

本项目包含 Web 端与微信小程序端两套架构：
- `web-mvp/`：目前用于初评演示的纯前端 Web 高保真原型，基于原生 HTML/JS + Bootstrap 5。
- `miniprogram/`：赛后迭代的微信小程序与云开发版本（规划中），采用原生小程序框架。

## 快速开始 (Web 端)

进入 `web-mvp/` 目录，使用 Live Server 打开 `index.html` 即可预览。或者直接访问[线上部署链接](https://jiangxueqi415.github.io/question-hub/)。

## Web MVP 当前规则

- 初始积分 0、信誉分 0；新人任务一次性获得 40 信誉分（不加积分），发布仍需先完成他人问卷攒够 10 积分。
- 完成一份问卷：+5 积分、+5 信誉分。
- 发布一份问卷：-10 积分，且信誉分必须 ≥ 40；未满足时按条件提示。
- 问卷支持开始/截至日期、单选/多选/开放题；开放题作答上限 100 字。
- 发布者在详情页和个人中心“我发布的问卷”中查看作答统计条形图与开放题作答；作答者不显示统计。
- 答题逾期未完成：扣 20 信誉分，不扣积分。
- 首页只展示待填写问卷；已完成/已过期收成列表底部一行入口，全部完成后显示空状态，记录仍可在个人中心查看。
- 详细接口、数据结构与验收清单见 [协作约定](docs/协作约定-发布页与个人中心.md)。
