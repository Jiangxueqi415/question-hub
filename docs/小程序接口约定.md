# 小程序接口约定

> 代码位置：`question-hub/miniprogram`
> 更新日期：2026-11-14
> 用途：与后端联调时对照「请求参数长什么样、返回 JSON 应有哪些字段」
> 现状：小程序直连 `http://10.30.96.49:8080/api`，`services/api.js` 已按真实后端返回值做归一化；
> 后端暂未实现的接口由页面按“无数据 / 暂不支持”降级，不再使用本地假数据。

## 0. 真实后端已实现接口（联调基准）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/auth/login` | `{ code }` → 未绑定时 `{ needBind:true, openid }`；已绑定时 `{ needBind:false, user, token }` |
| POST | `/auth/bind` | `{ openid, studentNo, nickname }` → `{ user, token }` |
| GET | `/surveys` | 问卷列表，题目在 `questionsJson` 字符串里 |
| GET | `/surveys/my` | 当前用户发布的问卷 |
| POST | `/surveys` | 创建问卷，题目通过 `questionsJson` 提交 |
| POST | `/surveys/{id}/submit` | `{ answers }` → 提交结果文案（字符串） |
| GET | `/surveys/{id}/stats` | 仅发布者可查看 |

**后端暂未实现**：`GET /me`、`PATCH /auth/me`（当前返回 400）、`/me/ledger`、`/me/surveys`、
`/me/responses`、`/me/onboard`、问卷详情、开始作答、编辑与下架。
小程序侧对应处理：

- `getMe()`：用 `wx.login` + `POST /auth/login` 刷新用户对象；
- 流水、我的作答：返回空列表，页面展示“后端暂未提供”；
- 新人任务、昵称修改、编辑/下架：`services/api.js` 明确返回 `NOT_SUPPORTED`，页面隐藏入口或提示；
- 参与人数：后端列表未返回，页面显示“参与人数待统计/以后端统计为准”；
- 提交结果：后端只返回文案，详情页直接展示文案，不推断 valid/invalid 状态。

下文第 1 节起保留客户端的字段期望，作为后端后续补齐接口时的目标契约。

## 0.1 相关文件

| 文件 | 作用 |
|---|---|
| `config/index.js` | 后端接口根地址 `baseUrl = http://10.30.96.49:8080/api` |
| `data/templates.js` | 发布页快捷模板（纯前端静态配置，不走接口） |

小程序本地只保存登录 token、openid 与用户快照（`utils/auth.js`），业务数据全部由后端持久化。

## 1. 通用约定

### 1.1 请求与响应

小程序端要求后端统一包一层：

```json
{ "code": 0, "message": "ok", "data": { } }
```

- `code === 0` 或 `code === undefined` 且 HTTP 2xx 视为成功，前端取 `data`；
- `code !== 0` 走业务错误，前端拿到 `Error`，`err.code` 为业务码；
- HTTP 401 或 `code === "AUTH_REQUIRED"` 会清 session 并 `reLaunch` 到登录页；
- 时间字段全部是**毫秒时间戳 Number**（不是字符串）；
- 请求头带 `Authorization: Bearer <token>`；token 由 `POST /auth/login` 或 `POST /auth/bind` 返回。

### 1.2 鉴权范围

| 范围 | 接口 |
|---|---|
| 无需绑定学号 | `POST /auth/login`、`GET /me`、`GET /surveys`、`GET /surveys/{id}` |
| 未绑定时返回空数组而不是报错 | `GET /me/ledger`、`GET /me/surveys`、`GET /me/responses` |
| 必须已绑定学号 | `PATCH /me`、`POST /me/onboard`、`POST /surveys`、`PATCH /surveys/{id}`、`POST /surveys/{id}/start`、`POST /surveys/{id}/submit`、`GET /surveys/{id}/stats`、`POST /surveys/{id}/close` |

### 1.3 用户对象（多处复用）

```json
{
  "id": "u_10001",
  "nickname": "校园用户",
  "points": 0,
  "credit": 0,
  "level": "较差",
  "levelTone": "poor",
  "onboarded": false,
  "bound": false
}
```

`level` / `levelTone` 由信誉分推导：85–100 优秀/excellent、70–84 良好/good、40–69 一般/fair、0–39 较差/poor。

### 1.4 幂等

- `POST /surveys` 与 `POST /surveys/{id}/submit` 支持请求体里的 `requestId`；
- 同一 `requestId` 重复请求，返回首次成功结果；
- 发布页生成 `publish_<时间>_<随机>`，作答页生成 `submit_<surveyId>_<时间>`。

## 3. 接口清单（16 个）

### 3.1 身份

#### `POST /auth/login`

请求：

```json
{ "code": "wx.login 返回的临时登录凭证" }
```

返回：

```json
{
  "token": "<服务端签发的登录态>",
  "user": { "id": "u_10001", "nickname": "校园用户", "points": 0, "credit": 0, "level": "较差", "levelTone": "poor", "onboarded": false, "bound": false },
  "needBind": true
}
```

- `needBind = !user.bound`；未绑定也允许进入首页浏览。

#### `POST /auth/bind`

请求：

```json
{ "studentNo": "2023001234", "nickname": "张三" }
```

校验：`studentNo` 必须 10–12 位数字；`nickname` 2–20 字、不能含控制字符。

返回：

```json
{
  "token": "<服务端签发的登录态>",
  "user": { },
  "needBind": false
}
```

错误：`INVALID_PARAMS`、`STUDENT_ALREADY_BOUND`（当前微信已绑定，或学号已被其他微信绑定）。

### 3.2 用户

#### `GET /me`

请求：无。

返回：用户对象（见 1.3）。

#### `PATCH /me`

请求：

```json
{ "nickname": "新昵称" }
```

返回：

```json
{ "user": { } }
```

错误：`STUDENT_NOT_BOUND`、`INVALID_PARAMS`。修改成功后同步自己发布问卷的 `ownerName`。

#### `POST /me/onboard`

请求：无。

返回：

```json
{
  "user": { },
  "creditDelta": 40,
  "already": false
}
```

- 只能领一次；已领取时 `creditDelta = 0`、`already = true`；
- 信誉分 0–100 截断，实际到账可能小于 40。

> 该接口 PRD 第 9 节未列出，README 已标注需与后端确认。

#### `GET /me/ledger?type=points|credit`

请求：query `type`，缺省或非 `credit` 都按 `points` 处理。

返回：数组，最多 60 条：

```json
[
  {
    "id": "pl_xxx",
    "delta": 5,
    "reason": "有效完成问卷：《xxx》",
    "surveyId": "s1",
    "balanceAfter": 5,
    "createdAt": 1730000000000,
    "type": "points"
  }
]
```

未绑定学号时返回 `[]`。

#### `GET /me/surveys`

请求：无。

返回：我发布的问卷摘要数组：

```json
[
  {
    "id": "s4",
    "title": "仲景文化认知调查",
    "description": "……",
    "category": "学习调研",
    "status": "open",
    "statusText": "进行中",
    "questionCount": 4,
    "participantCount": 42,
    "startAt": 0,
    "endAt": 0,
    "createdAt": 0,
    "responseCount": 0,
    "validCount": 0,
    "invalidCount": 0,
    "incompleteCount": 0,
    "expiredCount": 0,
    "hasResponses": true
  }
]
```

- `participantCount` 为参与人数（至少包含非 expired 的 response 数）；
- `responseCount = valid + invalid + incomplete`（不含 expired）；
- `hasResponses` 为真当且仅当该问卷存在真实 response；
- `status` 按 `endAt` 实时推导为 `open` / `closed`。

#### `GET /me/responses`

请求：无。

返回：我填写过的问卷数组：

```json
[
  {
    "id": "resp_xxx",
    "surveyId": "s1",
    "surveyTitle": "大学生网购消费习惯调查",
    "surveyExists": true,
    "status": "valid",
    "statusText": "已完成",
    "flags": [],
    "flagLabels": [],
    "answers": { "s1q1": 2, "s1q2": [0, 2], "s1q3": "文字答案" },
    "hasAnswers": true,
    "pointsEarned": 5,
    "creditDelta": 5,
    "createdAt": 0,
    "submittedAt": 0
  }
]
```

- `status`：`valid` / `invalid` / `incomplete` / `expired`；
- `statusText`：已完成 / 未通过质量核验 / 未答完 / 已过期；
- `flags` 取值：`fast`（作答时长过短）、`straight`（直线作答）、`open_invalid`（开放题无效）；
- `answers` 的值为：单选 = 选项下标 Number；多选 = 选项下标数组；开放题 = 字符串；
- `hasAnswers = status !== "expired" && 有答案`；
- 未绑定学号时返回 `[]`。

### 3.3 问卷浏览与作答

#### `GET /surveys?status=open`

请求：query `status=open`。

返回：可作答问卷摘要数组：

```json
[
  {
    "id": "s1",
    "title": "大学生网购消费习惯调查",
    "description": "……",
    "ownerName": "林同学",
    "category": "生活服务",
    "minutes": 3,
    "questionCount": 4,
    "participantCount": 36,
    "reward": 5,
    "startAt": 0,
    "endAt": 0,
    "createdAt": 0,
    "status": "open",
    "mine": false
  }
]
```

过滤规则：只返回未截止、非自己发布、且自己**没有任何 response**（含 expired）的问卷，按 `createdAt` 倒序。`reward` 为常量 5。

#### `GET /surveys/{id}`

请求：路径参数 `id`。

返回：问卷详情：

```json
{
  "id": "s1",
  "title": "大学生网购消费习惯调查",
  "description": "……",
  "ownerId": "u_demo_1",
  "ownerName": "林同学",
  "category": "生活服务",
  "minutes": 3,
  "reward": 5,
  "startAt": 0,
  "endAt": 0,
  "createdAt": 0,
  "participantCount": 36,
  "responseCount": 0,
  "hasResponses": false,
  "status": "open",
  "mine": false,
  "questions": [
    {
      "id": "s1q1",
      "type": "single",
      "title": "你平均每月网购几次？",
      "options": [
        { "id": "s1q1_o1", "text": "1-2 次" },
        { "id": "s1q1_o2", "text": "3-5 次" }
      ]
    }
  ]
}
```

- `hasResponses` 对非发布者恒为 `false`；对发布者 = 存在真实 response；
- `status` 按 `endAt` 推导，可能为 `closed`；
- 错误：`SURVEY_NOT_FOUND`。

#### `POST /surveys/{id}/start`

请求：无 body。

返回：

```json
{
  "attemptId": "att_xxx",
  "startedAt": 1730000000000,
  "endAt": 1730000000000,
  "status": "in_progress"
}
```

- 已有 `in_progress` attempt 时复用，不重复创建；
- 错误：
  - `SURVEY_NOT_FOUND`
  - `SELF_ANSWER_FORBIDDEN`（不能答自己的问卷）
  - `SURVEY_CLOSED`（已截止）
  - `ALREADY_SUBMITTED`（已提交过，`err.response` 带上 `GET /me/responses` 的单条结构，前端直接进入只读回看）

#### `POST /surveys/{id}/submit`

请求：

```json
{
  "attemptId": "att_xxx",
  "answers": {
    "s1q1": 2,
    "s1q2": [0, 2],
    "s1q3": "开放题文字"
  },
  "requestId": "submit_s1_1730000000000"
}
```

- `answers` 的 key 是题目 id；
- 单选传选项下标 Number；多选传下标数组；开放题传字符串（服务端 trim，最长截断 100 字）；
- 不合法/越界的答案会被忽略，未答超过 20% 判 `incomplete`。

返回（提交结果）：

```json
{
  "responseId": "resp_xxx",
  "status": "valid",
  "flags": [],
  "flagLabels": [],
  "pointsDelta": 5,
  "creditDelta": 5,
  "points": 5,
  "credit": 5,
  "missedCount": 0,
  "message": "提交成功：+5 积分、+5 信誉分"
}
```

- `status`：`valid` / `invalid` / `incomplete` / `expired`；
- `pointsDelta` / `creditDelta` 是本次实际结算值：
  - valid：+5 积分、+5 信誉
  - incomplete：0 积分、-5 信誉
  - invalid：0 / 0
  - expired：0 积分、-20 信誉（仅逾期结算时）
- `points` / `credit` 是结算后的最新值；
- `missedCount` 为未答题数；
- `message` 是给前端直接展示的整句文案；
- 错误：`SURVEY_NOT_FOUND`、`SELF_ANSWER_FORBIDDEN`、`ATTEMPT_EXPIRED`（作答记录失效或已截止）、`STUDENT_NOT_BOUND`；
- 幂等：同 `requestId` 直接返回首次结果；已有 response 时即使不带 `requestId` 也会重放首次结果。

### 3.4 发布与管理

#### `POST /surveys`

请求：

```json
{
  "title": "校园问卷标题",
  "description": "简介，可空",
  "category": "学习调研",
  "minutes": 3,
  "startAt": 1730000000000,
  "endAt": 1730000000000,
  "questions": [
    {
      "type": "single",
      "title": "题目 1",
      "options": ["选项 A", "选项 B"]
    },
    {
      "type": "open",
      "title": "题目 2",
      "options": []
    }
  ],
  "requestId": "publish_1730000000000_ab12cd"
}
```

校验规则：

- `title` 2–40 字；`description` ≤ 200 字；
- `category` ∈ `学习调研 / 生活服务 / 社团活动 / 其他`；
- `minutes` 1–60；
- `startAt` / `endAt` 必填，`endAt > startAt` 且 `endAt > 当前时间`；
- `questions` 1–25 道；
- 单选/多选必须有 2–6 个不重复选项，单选项 ≤ 50 字；开放题 `options` 忽略；
- 空选项行会被清洗掉；`type` 非法时按 `single` 处理。

返回：

```json
{ "id": "s_xxx", "points": 0, "credit": 40 }
```

- 门槛：`credit >= 40`、`points >= 10`，发布扣 10 积分；
- 错误：`CREDIT_NOT_ENOUGH`、`POINTS_NOT_ENOUGH`、`INVALID_PARAMS`、`STUDENT_NOT_BOUND`。

#### `PATCH /surveys/{id}`

请求：与 `POST /surveys` 相同（`requestId` 不使用）。

返回：

```json
{
  "id": "s_xxx",
  "survey": { "问卷详情结构，同 GET /surveys/{id}" },
  "points": 0,
  "credit": 40
}
```

规则：

- 只能编辑自己的问卷；
- 已有作答（存在 response）时，**题目内容/选项/题型不可改**，只能改标题、简介、分类、耗时、时间；改动题目会返回 `SURVEY_HAS_RESPONSES`；
- 没有作答时可以整体替换题目，题目/选项会重新生成 id；
- 错误：`SURVEY_NOT_FOUND`、`FORBIDDEN`、`INVALID_PARAMS`、`SURVEY_HAS_RESPONSES`、`STUDENT_NOT_BOUND`。

#### `POST /surveys/{id}/close`

请求：无 body。

返回：问卷详情结构（同 `GET /surveys/{id}`），其中 `status = "closed"`。

错误：`SURVEY_NOT_FOUND`、`FORBIDDEN`（只能下架自己的）。

#### `GET /surveys/{id}/stats`

请求：无。

返回：

```json
{
  "id": "s1",
  "title": "大学生网购消费习惯调查",
  "description": "……",
  "status": "open",
  "statusText": "进行中",
  "participantCount": 36,
  "responseCount": 0,
  "hasResponses": true,
  "questions": [
    {
      "id": "s1q1",
      "type": "single",
      "title": "你平均每月网购几次？",
      "total": 36,
      "selectionTotal": 36,
      "options": [
        { "text": "1-2 次", "count": 12, "percent": 33.3 },
        { "text": "3-5 次", "count": 10, "percent": 27.8 }
      ],
      "answers": []
    },
    {
      "id": "s2q4",
      "type": "open",
      "title": "你对食堂还有什么建议？",
      "total": 8,
      "selectionTotal": 8,
      "options": [],
      "answers": ["希望增加夜宵窗口", "建议错峰供餐，减少排队"]
    }
  ]
}
```

- 只能看自己发布的问卷统计；
- 选择题：
  - `total` = 该题作答人数；
  - `selectionTotal` = 各选项 count 之和（多选题会大于 total）；
  - `percent = count / total * 100`，保留 1 位小数；**多选百分比之和可以超过 100**；
- 开放题：`total` / `selectionTotal` 都是答案条数，`options` 为空，`answers` 是字符串数组；
- `participantCount` 为参与人数（至少包含非 expired response 数）；
- 错误：`SURVEY_NOT_FOUND`、`FORBIDDEN`。

## 4. 错误码清单

| code | 含义 / 触发场景 |
|---|---|
| `AUTH_REQUIRED` | 未登录 / token 失效（HTTP 401） |
| `STUDENT_NOT_BOUND` | 未绑定学号却调用需绑定接口 |
| `STUDENT_ALREADY_BOUND` | 当前微信已绑定，或学号已被其他微信绑定 |
| `SURVEY_NOT_FOUND` | 问卷不存在 |
| `SURVEY_CLOSED` | 问卷已截止 |
| `SELF_ANSWER_FORBIDDEN` | 发布者不能作答自己的问卷 |
| `ALREADY_SUBMITTED` | 已提交过；`err.response` 附带首次作答结果 |
| `SURVEY_HAS_RESPONSES` | 已有作答却试图改题目 |
| `FORBIDDEN` | 非本人问卷的编辑 / 统计 / 下架 |
| `POINTS_NOT_ENOUGH` | 积分不足 10 |
| `CREDIT_NOT_ENOUGH` | 信誉分不足 40 |
| `ATTEMPT_EXPIRED` | attempt 不存在、已失效或问卷已截止 |
| `QUALITY_INVALID` | 可选：质量核验不通过（也可用 `status: invalid` 表达） |
| `INCOMPLETE` | 可选：未答完（也可用 `status: incomplete` 表达） |
| `RATE_LIMITED` | 可选：服务端限流 |
| `INVALID_PARAMS` | 参数校验不通过，`message` 为具体提示 |
| `NOT_FOUND` | 路由不存在 |
| `SERVER_ERROR` | 兜底服务异常 |
| `NETWORK_ERROR` | `wx.request` 失败 |

前端按 `err.code` 做分支的场量：`ALREADY_SUBMITTED` 会带 `err.response`；`SURVEY_NOT_FOUND`、`SELF_ANSWER_FORBIDDEN`、`SURVEY_CLOSED`、`ATTEMPT_EXPIRED`、`STUDENT_NOT_BOUND`、`POINTS_NOT_ENOUGH`、`CREDIT_NOT_ENOUGH` 在页面里有专门处理。

## 5. 业务规则与常量

### 5.1 积分 / 信誉

| 规则 | 数值 |
|---|---|
| 初始积分 / 信誉 | 0 / 0 |
| 信誉范围 | 0–100（越界截断） |
| 新人任务 | +40 信誉、0 积分，仅一次 |
| 有效完成问卷 | +5 积分、+5 信誉 |
| 未答完（未答 > 20%） | 0 积分、-5 信誉 |
| 逾期未提交 | -20 信誉，只扣一次 |
| 发布问卷 | 扣 10 积分；要求信誉 ≥ 40、积分 ≥ 10 |
| 首页展示的完成奖励 | 固定 `reward: 5` |

### 5.2 质量核验

| 标记 | 规则 |
|---|---|
| `incomplete` | 未答题数 / 总题数 > 20% |
| `fast` | 作答 ≤ 2 秒直接 `invalid`；2–3 秒记 `fast` 标记 |
| `straight` | 选择题（≥ 2 道）同选项占比 ≥ 80% |
| `open_invalid` | 开放题去空格后 < 4 字，或单字符占比 ≥ 80%；白名单：无 / 没有 / 暂无 |
| 判定 | `flags >= 2` → `invalid`；`flags <= 1` → `valid`（1 个标记仍有效，只记录） |

### 5.3 字段限制

| 字段 | 限制 |
|---|---|
| 昵称 | 2–20 字 |
| 学号 | 10–12 位数字 |
| 问卷标题 | 2–40 字 |
| 问卷简介 | ≤ 200 字 |
| 题目数量 | 1–25 |
| 题目标题 | ≤ 100 字 |
| 选项数量 | 2–6 |
| 单选项文字 | ≤ 50 字 |
| 预计耗时 | 1–60 分钟 |
| 开放题答案 | ≤ 100 字（服务端截断） |
| 分类 | 学习调研 / 生活服务 / 社团活动 / 其他 |
| 题型 | single / multiple / open |

### 5.4 客户端行为

- 每个微信账号独立登录；小程序本地只保存 token 与用户快照；
- `startSurvey` 返回服务端创建的 attempt；已有进行中的 attempt 时复用，不重复创建；
- `attempt.endAt` 为开始作答时对问卷 `endAt` 的快照；
- 逾期结算由服务端完成，客户端只展示结果；
- 发布页与作答页在请求体中携带 `requestId`，服务端需保证幂等；
- ledger 接口建议最多返回 60 条，避免列表过长。

## 6. 已知契约缺口 / 联调注意

1. `POST /me/onboard`、`PATCH /me` 不在 PRD 第 9 节接口表中，需后端确认；
2. `GET /me/responses` 目前返回完整 `answers`，生产环境建议加 `GET /me/responses/{id}`，列表接口不携带答案全文；
3. `GET /surveys?status=open` 的 `status` 参数需后端支持状态过滤；
4. 未绑定时 `GET /me/ledger`、`/me/surveys`、`/me/responses` 返回 `[]` 而不是 `STUDENT_NOT_BOUND`，后端需确认这个行为；
5. `QUALITY_INVALID`、`INCOMPLETE`、`RATE_LIMITED` 为可选错误码，客户端已按业务错误处理；
6. 必须把身份、计时、判重、幂等、质量判定、结算全部放服务端；
7. 学号必须使用 HMAC-SHA256 + 服务端盐值保存，且不采集真实姓名、手机号、IP。
