# question-hub

校园问卷互助积分平台

本项目为南阳师范学院第二十三届“张衡杯”大学生课外学术科技作品竞赛 - 科技发明制作 B 类（信息技术）参赛作品。

│  ├─ index.html       # 首页

│  ├─ publish.html     # 发布问卷

## 两端说明

本项目按端拆分为两个目录，互不影响：

- **`web-mvp/`**：当前已完成的纯前端演示版本，原生 HTML + CSS + JavaScript + Bootstrap 5（CDN），数据存在浏览器 `localStorage`。直接打开 `web-mvp/index.html` 即可运行。
- **`miniprogram/`**：微信小程序端占位目录。计划采用原生微信小程序 + 微信云开发实现，把身份去重、发布/领取事务、质量核验放到服务端；目前仅保留 `README.md`，尚未开始编码。

两端的定位不同：`web-mvp` 用于课堂演示与答辩展示，`miniprogram` 用于后续小范围真实试用。数据不互通，小程序端会重新设计云端数据模型。

## 项目简介

本项目针对在校大学生调研问卷收集困难、填写率低、付费刷问卷导致数据虚假的痛点，设计了一款基于“积分互助”机制的轻量级 Web 原型。用户通过填写他人问卷获取积分，消耗积分发布个人问卷，实现校内学生的互帮互助与真实数据收集。

## 技术栈

- 前端基础：HTML5 + CSS3 + 原生 JavaScript
- UI 框架：Bootstrap 5（CDN 引入）
- 数据存储：浏览器 `localStorage`（用于模拟后端数据流转）
- 协作工具：Git + GitHub
- 后续小程序端：原生微信小程序 + 微信云开发（规划中）

## 本地运行指南

1. 克隆本仓库到本地：`git clone <仓库链接>`
2. 使用 VS Code 打开项目文件夹。
3. 安装并启用 Live Server 插件。
4. 在 `web-mvp/index.html` 上右键，选择 **Open with Live Server**。

也可以进入 `web-mvp` 目录后启动任意静态服务器：

```bash
cd web-mvp
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/index.html
```

## 核心业务流程

1. 赚积分：首页点击问卷 → 进入详情页 → 答完题点击“提交问卷并领取积分” → 积分增加，按钮置灰（防重复机制）。
2. 花积分：点击底部“发布问卷” → 填写表单 → 发布成功 → 扣除积分并返回首页。
3. 信誉分：完成新人任务、有效答卷可增加信誉分；信誉分达到 40 才能发布问卷。
4. 数据查看：在“我的”页面查看积分/信誉流水、我发布的问卷与我填写过的问卷。
