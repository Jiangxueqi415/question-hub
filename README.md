# 互答有据 - 校园问卷互助系统

一个“先帮别人填问卷、再发布自己的问卷”的校园互助原型：用积分记录互助贡献，用信誉分约束发布与作答质量。

> 术语说明：`MVP` 是最小可行产品的范围概念；`web-mvp` 是已完成的网页版实现；`小程序 MVP` 是下一步要交付的微信小程序版本。

## 两端结构

| 目录 | 说明 | 状态 |
|---|---|---|
| `web-mvp/` | 网页版高保真原型，原生 HTML/CSS/JS + Bootstrap 5（CDN） | 已完成，可线上演示 |
| `miniprogram/` | 微信小程序端，原生小程序框架 | 规划中，暂无业务代码 |
| `docs/` | PRD、接口协作约定等文档 | 持续更新 |

小程序端拟采用 **原生微信小程序 + Spring Boot + MySQL**，把身份、计时、判重、结算放到服务端；网页版继续作为交互与业务规则参考，不作为小程序代码基础。

## 快速开始（网页版）

线上地址：<https://jiangxueqi415.github.io/question-hub/>

本地预览：

```bash
cd web-mvp
python -m http.server 8000
# 打开 http://localhost:8000
```

页面通过 CDN 加载 Bootstrap，首次打开需要联网；数据保存在当前浏览器的 `localStorage`，换浏览器或设备不会同步。

## 当前规则（网页版）

- 初始积分 0、信誉分 0；新人任务一次性获得 40 信誉分，不加积分。
- 完成一份有效问卷：+5 积分、+5 信誉分。
- 发布一份问卷：扣 10 积分，且信誉分必须 ≥ 40。
- 质量校验：总用时不足 3 秒、漏答率超过 20%、直线作答、开放题无效等会命中标记；命中达到阈值判为无效，不发放积分。
- 未答完提交（漏答超过 20%）：不发积分、扣 5 信誉分，记录标记为“未答完”，可在个人中心查看，不能重复提交。
- 领取后逾期未提交：扣 20 信誉分，不扣积分。
- 问卷支持开始/截止日期、单选/多选/开放题；开放题最多 100 字。
- 发布者可在详情页和个人中心查看作答统计与开放题原文；发布者不能填写自己的问卷。
- 首页只展示待填写问卷；已完成/已过期收成底部一行入口；全部完成后显示空状态。
- 填写记录保留 7 天，过期后自动清理；积分与信誉变动均记录时间与原因。

详细规则、页面流程、接口与验收清单见 [PRD-小程序-v1.0.md](docs/PRD-小程序-v1.0.md)；发布页与个人中心的协作约定见 [协作约定-发布页与个人中心.md](docs/协作约定-发布页与个人中心.md)。

## 技术栈

- 网页版：原生 HTML、CSS、JavaScript，Bootstrap 5（CDN）
- 数据：浏览器 `localStorage`（单浏览器演示，非真实多用户）
- 部署：GitHub Actions → GitHub Pages，发布 `web-mvp/`
- 小程序（规划）：原生微信小程序 + Spring Boot + MySQL

## 已知边界

- 网页版是单机原型，无法实现跨设备身份、真正“一人一卷”和跨设备统计。
- 学号哈希、跨设备去重、答卷导出等能力属于小程序/后端阶段。
- 当前未接入真实用户试验，页面中的演示数据仅用于流程展示。
